#### 📌 Featured projects
**[PDV Agent — AI-assisted VAT reconciliation for accounting firms](https://github.com/geloai/pdv-agent)**
An AI agent that prepares the monthly Croatian VAT return: it **reconciles the books with fiscalized eRačuni and the bank, reads foreign PDF invoices, drafts the return and flags every exception** with a plain-language explanation for the accountant to review.
